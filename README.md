# Ádám Sándor Fotós – szerkeszthető weboldal V5

A V5 már tartalmazza a Decap CMS szerkesztőfelületét az `admin/` mappában.

## Fontos
A szerkesztőfelület végleges működéséhez a weboldalt fel kell tölteni egy GitHub repóba, majd az `admin/config.yml` fájlban be kell állítani a saját GitHub repót és a végleges domaint. Ezt együtt fogjuk beállítani; most nem kell semmilyen kódot módosítanod.

A weboldal látogatói nem látják az adminfelületet. A szerkesztő külön címen érhető el: `/admin/`.

A szerkesztőben a főbb részek külön kezelhetők: Alapadatok, Nyitó rész, Rólam, Szolgáltatások, Folyamat, Galéria és GYIK.
